# 🔐 Random Password Generator

A small, fun JavaScript practice project: a random password generator web app. Click the button to instantly generate a strong 14-character password made of uppercase & lowercase letters, digits and symbols, then copy it to your clipboard with a single tap — with an animated confirmation alert.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Features

- 🎲 **One-click generation** of a 14-character random password
- 🔡 **Strong character set** — `a-z`, `A-Z`, `0-9` and symbols (`!@#$%^&*_-`)
- 📋 **Copy to clipboard** via the Clipboard API with a click on the copy icon
- 🔔 **Animated confirmation alert** ("password copied!") that auto-dismisses
- 🎨 Clean, centered card UI styled with custom CSS and Material Symbols icons

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** — custom card UI
- **Vanilla JavaScript** — generation & clipboard logic (`app.js`)

## 🚀 Getting Started

```bash
git clone https://github.com/shena9y/Random-Password-Generator.git
cd Random-Password-Generator
```

Open `index.html` in your browser, hit **Generate Password**, and click the copy icon. 🔑
